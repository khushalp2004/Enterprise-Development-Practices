# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - Production Ready
### Added
- Enterprise-grade CI/CD pipeline using Jenkins.
- Full Kubernetes deployment manifests.
- Terraform infrastructure scripts for AWS EKS deployment.
- Prometheus and Grafana integration for monitoring 10,000+ metrics.
- Comprehensive security and compliance documentation.

## [0.9.0] - Polish and UI Enhancements
### Added
- PDF Receipt Generation for Sales using jsPDF.
- Inline editing and deletion capabilities for HR and Inventory modules.
- Global toast notifications (react-hot-toast) across all Next.js pages.
- Automatic routing logic for expired JWT tokens.

## [0.8.0] - Core Functionality Complete
### Added
- Event-driven architecture using Kafka for cross-module integration.
- Accounting module that listens to Sales events to create ledger entries.
- JWT Security setup and Role-Based Access Control.
- Basic CRUD operations for HR and Inventory.
